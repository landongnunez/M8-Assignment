# Module 08: Customer Management System

This repository showcases the use of core Python data structures—specifically dictionaries and lists—to manage business operations and project financials.

## Files Included
- `module08-assignment.py`: Python script demonstrating complex dictionary manipulations for customer and project tracking.

## What I Practiced
- **Nested Dictionaries:** Managing master customer records and project lists within a structured hierarchy.
- **Dictionary Comprehensions:** Creating adjusted rate tables and filtering active customers efficiently.
- **Financial Aggregation:** Calculating project costs, total budgets, and average spending across different company accounts.
- **Functional Logic:** Developing validation functions and a basic recommendation engine to suggest new services to existing clients.
- **Data Analysis:** Tracking project statuses and calculating service usage frequency.
